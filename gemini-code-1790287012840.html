Результат:

Генератор Микро-лендингов (Pixel Proxy)

Обычные короткие ссылки не собирают аудиторию. Сгенерируйте HTML-прокладку, загрузите её на свой хостинг, и она сначала отстучит в Meta Pixel, а затем перенаправит клиента на сайт.

Сохраните этот код как index.html и залейте на любой бесплатный хостинг (например, GitHub Pages). Рекламу запускайте на адрес этого хостинга.
